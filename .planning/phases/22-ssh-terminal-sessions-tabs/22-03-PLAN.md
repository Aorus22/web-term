   - Persist open tabs to `settings.open_sessions` whenever tabs are added, connected, or closed.

     - If detached sessions exist on the backend:
       - Match against `settings.open_sessions` or restore all active/detached sessions as tabs in `session_manager`.

       - Upon attach success, backend replays scrollback via `"ready"`, and the terminal is fully restored.
     - If no existing sessions exist, fall back to opening a fresh local shell tab.
