## Objective
Implement and execute automated chaos resilience and high-throughput terminal performance test suites:
1. Terminal throughput & bounded memory test (`desktop-gpui/crates/terminal/tests/performance_test.rs`):
   - Stream 50,000 lines (multi-megabyte burst) of ANSI escape sequences, color shifts, and cursor jumps.
   - Verify processing speed (>10,000 lines/sec) and zero panics.
   - Verify bounded memory: scrollback history strictly adheres to `max_scrollback` limit without unbounded allocation.
2. Reconnection chaos tests (`desktop-gpui/crates/webterm/tests/chaos_test.rs`):
   - Chaos Scenario 1 (WS drop): Abrupt socket closure triggers backoff retry loop while preserving active terminal grid state and scrollback.
   - Chaos Scenario 2 (Backend kill): Abrupt backend termination is cleanly trapped by `Supervisor`, transitioning to `BackendStatus::Crashed`.
   - Chaos Scenario 3 (App restart): Persisted sessions in `settings.json` survive cold app restart and restore tab order and metadata for re-attach.
