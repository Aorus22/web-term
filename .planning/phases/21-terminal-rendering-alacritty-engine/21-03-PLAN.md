  <action>
1. Create desktop-gpui/crates/terminal/src/render.rs:
   - Implement CellDimensions measuring 'M' character width and line height from text system.
   - Implement background quad coalescing (merging adjacent same-color background cells).
   - Implement text run batching (grouping adjacent cells with identical font styles into BatchedTextRun).
   - Implement cursor rendering (block, beam, underline) matching terminal focus state.
   - Implement selection highlight rendering over selected cell ranges.

2. Create desktop-gpui/crates/terminal/src/input.rs:
   - Map GPUI KeyDownEvent into ANSI escape bytes:
     - Enter -> "\r"
     - Backspace -> "\x7f" or "\x08"
     - Tab -> "\t", Shift+Tab -> "\x1b[Z"
     - Arrow keys -> "\x1b[A", "\x1b[B", "\x1b[C", "\x1b[D" (and application mode sequences)
     - Home, End, PageUp, PageDown, Delete
     - Control combinations: Ctrl+A through Ctrl+Z -> 1..26
     - Function keys F1..F12

3. Create desktop-gpui/crates/terminal/src/mouse.rs:
   - Convert GPUI mouse click/drag points to terminal grid (col, row) coordinates.
   - Handle selection start on mouse down, range expansion on drag, and selection commit on mouse up.
  </action>
