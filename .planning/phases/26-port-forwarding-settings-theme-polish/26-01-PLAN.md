# Plan 26-01: Port Forwarding Management UI

## Frontmatter
- **Phase:** 26-port-forwarding-settings-theme-polish
- **Plan:** 26-01
- **Requirement:** FWD-01 (User can create and manage local port forwarding rules from the desktop app)
- **Status:** Ready

## Objective
Implement end-to-end port forwarding support in the desktop GPUI client:
1. Extend `webterm-backend-client` with port forwarding types (`PortForward`, `CreateForwardRequest`, `UpdateForwardRequest`) and REST methods (`list_forwards`, `create_forward`, `update_forward`, `delete_forward`, `start_forward`, `stop_forward`).
2. Add automated contract test `backend-client/tests/forwards_api_test.rs` validating all endpoints against mock server.
3. Extend `AppState` with `View::Forwards`, port forward listing state, start/stop toggle, deletion confirmation, and modal form state (`ForwardFormState`).
4. Implement `views/forwards.rs` providing forward rule cards, status badges (active/inactive, local/reverse, error indicator), start/stop switch, edit and delete actions, and create/edit modal.
5. Integrate `View::Forwards` into `views/nav.rs` sidebar navigation.
6. Add unit test `webterm/tests/forwards_view_test.rs` covering validation, port parsing, and state transitions.

## Proposed Changes

### Component: `backend-client`

#### [MODIFY] `desktop-gpui/crates/backend-client/src/types.rs`
- Add `PortForward`, `CreateForwardRequest`, `UpdateForwardRequest`, and helper functions matching the Go backend API.

#### [MODIFY] `desktop-gpui/crates/backend-client/src/rest.rs`
- Implement `list_forwards`, `get_forward`, `create_forward`, `update_forward`, `delete_forward`, `start_forward`, and `stop_forward`.

#### [NEW] `desktop-gpui/crates/backend-client/tests/forwards_api_test.rs`
- Comprehensive mock server contract tests covering listing, creation, update, delete, start, and stop.

### Component: `webterm`

#### [MODIFY] `desktop-gpui/crates/webterm/src/app_state.rs`
- Add `View::Forwards` to `View` enum.
- Add `forwards: Vec<PortForward>`, `is_loading_forwards: bool`, `forward_modal: Option<ForwardFormState>`, `delete_forward_target: Option<PortForward>`.
- Add methods: `fetch_forwards`, `open_create_forward_modal`, `open_edit_forward_modal`, `close_forward_modal`, `save_forward_form`, `toggle_forward_active`, `open_delete_forward_modal`, `close_delete_forward_modal`, `confirm_delete_forward`.

#### [NEW] `desktop-gpui/crates/webterm/src/views/forwards.rs`
- Render port forward list cards, active/inactive pill, type pill (Local vs Reverse), connection label, port mapping string (`localhost:X -> :Y` or `:Y <- localhost:X`), error indicator, toggle switch, edit/delete actions, and create/edit modal with connection picker, port inputs, type selector, and validation.

#### [MODIFY] `desktop-gpui/crates/webterm/src/views/mod.rs`
- Export `pub mod forwards;`.

#### [MODIFY] `desktop-gpui/crates/webterm/src/views/nav.rs`
- Add `(View::Forwards, "Port Forwards")` to sidebar items.
- Wire `View::Forwards` to `render_forwards_view` and modal overlays.

#### [NEW] `desktop-gpui/crates/webterm/tests/forwards_view_test.rs`
- Test `ForwardFormState` validation (name required, connection required, valid port range 1..65535, local vs reverse direction strings).
