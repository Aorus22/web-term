<action>
1. In `desktop-gpui/crates/webterm/src/app_state.rs`:
   - Add fields to `AppState`:
     - `pub ssh_keys: Vec<SshKey>`: cached keys list from backend `/api/keys`.
     - `pub is_loading_keys: bool`.
     - `pub show_add_key_modal: bool`.
     - `pub new_key_name: String`.
     - `pub new_key_pem: String`.
     - `pub pending_passphrase_conn: Option<(String, String)>`: `(connection_id, key_id)` waiting for passphrase.
     - `pub passphrase_input: String`.
     - `pub passphrase_cache: std::collections::HashMap<String, String>`: in-memory `key_id -> passphrase` session cache.
   - Implement methods:
     - `pub fn fetch_keys(&mut self, cx: &mut Context<Self>)`: calls `/api/keys`.
     - `pub fn create_key(&mut self, cx: &mut Context<Self>)`: encodes `new_key_pem` as base64, calls `client.create_key`, refreshes key list.
     - `pub fn delete_key(&mut self, id: &str, cx: &mut Context<Self>)`: calls `client.delete_key`.
     - `pub fn submit_passphrase(&mut self, cx: &mut Context<Self>)`: caches passphrase in memory and resumes terminal connection with passphrase.
     - `pub fn cancel_passphrase(&mut self, cx: &mut Context<Self>)`.
   - On supervisor `Ready`, also call `this.fetch_keys(cx)`.
2. Create `desktop-gpui/crates/webterm/src/views/keys.rs`:
   - Header with "SSH Keys", count badge, and "+ Add Key" button.
   - List of key cards:
     - Name, algorithm/type badge (e.g. "Ed25519", "RSA"), SHA256 fingerprint, creation timestamp.
     - Delete button with confirm.
   - Add Key modal overlay when `app.show_add_key_modal` is true:
     - Key Name input.
     - Private Key PEM textarea/input.
     - Action buttons: "Cancel" and "Save Key".
3. Create `desktop-gpui/crates/webterm/src/views/passphrase_modal.rs`:
   - Centered modal dialog when `app.pending_passphrase_conn.is_some()`:
     - Header: "Unlock SSH Key".
     - Description: "This key is passphrase-protected. Passphrase is kept in memory for this session only."
     - Masked password input field.
     - Action buttons: "Cancel" and "Unlock & Connect".
4. In `desktop-gpui/crates/webterm/src/views/nav.rs`:
   - Render `render_keys_view` when `active_view == View::Keys`.
   - Mount `render_passphrase_modal` overlay when `app.pending_passphrase_conn.is_some()`.
