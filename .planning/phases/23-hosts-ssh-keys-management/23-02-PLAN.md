   - Add fields to `AppState`:
     - `pub connections: Vec<Connection>`: cached connection list fetched from backend.
     - `pub search_query: String`: filter text for host cards.
     - `pub selected_tag: Option<String>`: active tag filter (None = all).
     - `pub is_loading_connections: bool`: indicates background fetch in progress.
   - Implement methods:
     - `pub fn fetch_connections(&mut self, cx: &mut Context<Self>)`: fetches `/api/connections` asynchronously.
     - `pub fn connect_to_host(&mut self, connection_id: &str, cx: &mut Context<Self>)`: opens an SSH tab with `WsConnectRequest::for_saved_connection(connection_id, 80, 24)` and switches active view to `View::Hosts` with terminal tab strip focused.
     - `pub fn set_search_query(&mut self, query: String, cx: &mut Context<Self>)`.
     - `pub fn select_tag_filter(&mut self, tag: Option<String>, cx: &mut Context<Self>)`.
   - On supervisor `Ready`, call `this.fetch_connections(cx)`.
2. Create `desktop-gpui/crates/webterm/src/views/hosts.rs`:
   - Top action bar:
     - Search input field (filters by label, host, username, or tag).
     - Tag filter chips horizontally scrollable or wrapped (e.g. "All", "prod", "dev", "database").
     - Action buttons: "+ Add Host", "Import", "Export" (wired to modal triggers in Plan 23-03).
   - Connection cards grid / flex-wrap container:
     - Each card:
       - Header with connection label and auth badge ("🔑 Key" or "🔒 Password").
       - Host info: `user@host:port`.
       - Tag chips with subtle rounded pill styling.
       - Quick "Connect" button that triggers `connect_to_host`.
       - Action buttons: "Edit" and "Delete" (with confirm).
     - Empty state when no connections match query or catalog is empty.
3. In `desktop-gpui/crates/webterm/src/views/nav.rs`:
   - Integrate `render_hosts_view` into the hosts pane when `View::Hosts` is selected, preserving the tab strip when open terminal sessions exist.
