<task type="auto">
  <name>Task 3: Supervisor crate — spawn, handshake, readiness, lifecycle</name>
  <reversibility rating="costly">Supervisor's public API (Supervisor/BackendStatus/BackendInfo) becomes the integration seam every later plan consumes.</reversibility>
  <files>desktop-gpui/crates/supervisor/src/lib.rs, desktop-gpui/crates/supervisor/tests/integration.rs</files>
  <read_first>be/cmd/server/main.go, be/internal/config/config.go, .planning/phases/20-desktop-foundation-backend-integration/20-RESEARCH.md</read_first>
  <action>
Implement crates/supervisor (crate name webterm-supervisor; tokio-only, no GPUI):

- `pub enum BackendStatus { Starting, Ready, Failed { reason: String, stderr_tail: String }, Crashed { exit_code: Option<i32> } }` — stderr_tail capped at 2000 chars, newest-wins.
- `pub struct SpawnOptions { backend_path: PathBuf, db_path: PathBuf, encryption_key: String (validated 64 hex chars), allowed_origins: String (default "null"), readiness_timeout: Duration (default 15s), handshake_timeout: Duration (default 15s) }` with builder methods.
- `pub struct Supervisor`: `spawn(opts) -> Result<BackendInfo>` — `tokio::process::Command` with `kill_on_drop(true)`, stdout piped to a line-reader task that parses the FIRST line matching `^BACKEND_PORT:(\d+)$` (per be/cmd/server/main.go — do not poll-guess ports), stderr piped into the tail ring; after handshake, poll `GET http://127.0.0.1:{port}/api/settings` every 250ms until HTTP 200 (any response proves the listener is up; the backend binds only after db.Init — see 20-RESEARCH §2.3) or readiness timeout; child exit before ready → `Failed` with stderr tail. Env injection exactly: `WEBTERM_PORT=":0"`, `WEBTERM_DB_PATH`, `WEBTERM_ENCRYPTION_KEY`, `WEBTERM_ALLOWED_ORIGINS` — secrets via env only, never argv.
- `pub struct BackendInfo { pub base_url: String, pub pid: u32 }`; `stop(grace 5s)` graceful-then-hard kill; `wait()` → Crashed for crash monitoring; status exposed via `tokio::sync::watch`.
- `adopt_or_clear(base_url: Option<String>) -> Option<BackendInfo>` — probe a previously recorded URL once (1s timeout): healthy → adopt (caller skips spawn); dead → None (fresh spawn). No PID files.

Unit tests for the handshake parser (`BACKEND_PORT:54321` → 54321, noise lines ignored, first-match-wins). Integration tests (tests/integration.rs), gated on TEST_BACKEND_PATH — when absent, `eprintln!` the build-fixture instruction and return early (loud skip, never a silent pass):
1. `spawns_real_backend_and_reaches_ready` — tempdir db, random 32-byte hex key; Ready within 15s; base_url matches `http://127.0.0.1:<port>`; stop() → process gone within 6s.
2. `invalid_path_reports_failed` — nonexistent backend_path → Failed with non-empty stderr tail.
3. `stop_terminates_child` — Ready then stop(grace 2s) → child exit confirmed.
4. `env_only_secrets` — SpawnOptions env map contains the key; its argv representation contains no key material.
  </action>
