<prohibitions>
- Prohibition 1: The desktop settings store must never hold SSH connection or key material. The backend decryption key is the deliberate single exception.
- Prohibition 2: Secrets are env-only, never argv, never logged. The Failed state's stderr tail must be scanned for key material before display (the backend prints a generated key only when env is unset — we always set it, but scan anyway).
- Prohibition 3: The backend base URL is not displayed or exported beyond the app's own use.
</prohibitions>
